Merge a friend's .fit file into yours when your head unit died

Your head unit or a sensor died partway through the ride. Someone who rode with you recorded it too. Take the missing parts from their file.

The problem

The recording stops, or a track such as GPS or power is missing for part of the ride. A friend has a file that covers it.

The steps

  1. Open your file.
  2. Choose Combine with Another File.
  3. Pick the second .fit file. Only your activity changes. The other file is never touched.
  4. Choose a source for each data track: GPS track, heart rate, power, cadence, speed or temperature. You can take only the time and the GPS track from theirs.
  5. If the two devices' clocks disagreed, shift the second file until the recordings line up. Tap the offset to reset it.
  6. Check the preview, then tap Combine. Save the file.

A ride that was split across two files joins the same way: the second file is appended right after the first.

The result

Your file now carries the data tracks you took from theirs, and the gap is filled.

Share it

Save it to Files as a new file or replace the original, send it through the share sheet, or upload it to Strava. If the activity is already on Strava, Strava rejects the new file as a duplicate: delete the original there first, then upload.
